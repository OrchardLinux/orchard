# Device compatibility

Generated by `tools/catalog/generate matrix` from `devices/`, `chips/` and `methods.toml`; do not edit by hand.

- **known:** identity and boot data only, from public sources. Orchard does not build for it yet.
- **experimental / supported:** Orchard builds for it. Feature states are below.
- **Install:** every requirement is met (`hardware.install_blockers`). Other features may not work yet.
- **Device tree:** the board has one in OrchardLinux/linux. It does not mean the board has booted.
- **boot.json:** the Apple boot files are known. It does not mean a method runs on the board.
- **GPU (dEQP):** the highest GLES suite that completes with no GPU hangs and only listed failures, through Zink.
