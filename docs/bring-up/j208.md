# iPad Pro 10.5 (Cellular, J208) RAM bring-up

Facts measured by vividmuse in RAM desktop sessions on an iPad Pro 10.5
Cellular (`iPad7,4`, T8011, chip `0x8011`, board `0x06`), kernel
`7.3.0-rc1-orchard-j208` built from Hoolock `6831bc701` with the old J71b
series, firmware read from the attached iPad (iPadOS 17.7.11, 21H461).
Submitted as #42; the code from those sessions is tagged
`contrib/vividmuse-j208` and listed, with the open work, in
[`devices/j208/README.md`](../../devices/j208/README.md).

| Identity | Value |
| --- | --- |
| Product | iPad Pro 10.5 (Cellular), `iPad7,4` |
| DFU | chip `0x8011`, board `0x06` |
| Device tree | `apple,j208`; mainline `t8011-j208.dts` |
| Kernel platform | `apple-16k` |

The RAM drivers were bring-up code, so "worked" below means worked in those
sessions, not that Orchard builds it.

## Wi-Fi

| Fact | Value |
| --- | --- |
| Chip | BCM4355 rev 10, PCI `14e4:43dc` |
| Location | PCIe root port 2 |
| OTP module selection | `YSBU`, `m`, `2.3` |
| Result | WPA2 association through brcmfmac |
| Controller setup | T8011 PCIe tunables from `AppleT8011PCIe::_commonInit` (21H461); unlike H9P, offset `0x24` is status and `0x28` a tunable, with no port-0 control write |
| Caveat | The chip reported stream-0 read faults during association when RX buffers were write-only for the device |
| Power | D2401 (`apple,autumn-pmic`) GPIO1 at `0x902` enables WLAN; values below `0x40` select input mode |

## Touch

The `apple_z2` variant from the sessions loaded firmware and captured valid
frames but registered no input device. The device-property order and
geometry it used are in `drivers/patches/0007` at the tag. D2400
(`apple,august-pmic`) LDO13 is enabled at `0x312` for the touch rail.

## Backlight

D2400 WLED: gate registers `0x307`–`0x309`, level at `0xb01` (high byte)
then `0xb00` (low byte), from `AppleD2400PMU` in 21H461. Brightness changed
in the sessions.

## Battery

| Fact | Value |
| --- | --- |
| Gauge | BQ27540 over HDQ (`ti,hdq-uart` + `ti,bq27540-hdq`) |
| UART | UART5 at `0x20a0d4000`, AIC IRQ 221 |
| Pin | AP GPIO 163, function 1 |
| Quirk | RemainingCapacity (`0x10`) answers; NAC (`0x0c`) does not |

Charging was not attempted.

## Light sensors

Two parts on I2C3 (`0x20a113000`) at addresses `0x29` and `0x39`; identity
register `0x92`. The sessions read identity, configuration and samples;
there is no Linux IIO driver for them yet.

## SmartIO

Firmware `apple/t8011-smartio.bin`, 557,168 bytes in the build used.
